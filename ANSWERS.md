# ANSWERS

## 1. How to run

Clone or download the repository and open index.html in a browser.

---

## 2. Stack & design choices

I used Vanilla HTML, CSS, and JavaScript because this project is small and does not require a framework.

One design decision was separating the form and results into two sections for better readability.

Another decision was using preset tip buttons because it makes interaction faster on mobile devices.

---

## 3. Responsive & accessibility

On mobile screens the layout changes into a single column.

On larger screens it uses a two-column layout.

I added proper labels for inputs and keyboard-friendly buttons.

I did not implement screen-reader live announcements due to time.

---

## 4. AI usage

I used ChatGPT for UI improvement suggestions and validation ideas.

The AI suggested a fixed layout, but I modified it into a responsive grid layout for better mobile support.

---

## 5. Honest gap

One thing not fully polished is advanced number formatting for very large values.

With another day I would improve currency formatting and animations.
